# n-body-simulation
This project is a SFML‑based N‑Body gravitational simulator. It reads a‬ universe description from a text file passed on the command line (including‬ each body’s initial position, velocity, mass, and image), scales those‬ real‑world coordinates to fit the window based on the universe radius, and‬ then computes the gravitational forces among all bodies each timestep. Using‬ Euler integration in the step() function, it updates every planet’s‬ acceleration, velocity, and position for the elapsed time, and continuously‬ redraws them in an SFML render loop so you can watch a dynamically evolving‬ solar system in motion.
